# Jiya Raisinghani – Personal Portfolio

## About the Project

This is my personal portfolio website, created as part of my HTML5 internship assignment. It introduces me, highlights my technical skills, shares my learning journey, and provides a way to contact me.

## Technologies Used

- HTML5
- Semantic HTML elements
- HTML Forms
- HTML Tables
- Hyperlinks and navigation

## Website Sections

- **Home:** Introduction and career objective.
- **About Me:** Background, interests, and learning experience.
- **Skills:** Programming languages and development tools.
- **Learning Journey:** Technologies I have learned and am currently exploring.
- **Education:** Academic background and areas of focus.
- **Contact Me:** Contact form with HTML validation.

## Features

- Semantic HTML5 structure.
- Navigation using internal links.
- Structured content using headings, paragraphs, and lists.
- Learning progress displayed in an HTML table.
- Contact form with required fields and native validation.
- External GitHub and email links.
